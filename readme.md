# (My) 1st Romaji Typing - Gemini 3.6-Flashへの依頼内容

## 1. 開発のねらい・指導コンセプト

* **スモールステップでのつまずき解消**
  * ローマ字入力のどこでつまずくか（母音・子音・キー配置等）を見きわめ、段階的に難しすぎない課題を提供する。
* **知識学習とタイピング実践の並行（即時フィードバック）**
  * 50音表の暗記を前提とせず、1文字・1単語「知ったその場で打つ」体験を繰り返し、成功体験を重ねることで記憶に定着させる。
* **ヒント待ち時間の視覚化と心理的安全性**
  * 待てばヒントや答えが浮かび上がる仕組みにより、「分からないので挫折」を防ぎ達成感につなげる。
* **記憶の定着度を「50音マップ（図鑑）」の色彩で可視化**
  * 自力で打てたか、ヒントを見て打ったかにより50音マスの色を変化させ、コンプリート欲（全体を緑・金色で満たしたい意欲）を引き出す。
  * ヒント依存で打ったマスは時間の経過で色が薄れる（間隔反復学習のアナロジー）ことで、自発的な復習を促す。

---

## 2. システム・UI/UX要件

### (1) 画面レイアウト・動作環境
* **iPad（第10世代・横置き 4:3）1画面完結型**
  * スクロール不要で全要素が収まる2段レイアウト。
    * **上段・左：** 出題カード ＆ ステップ選択バー
    * **上段・右：** QWERTYソフトキーボード（打鍵時に沈み込み/反転表示のフィードバック）
    * **下段：** 50音マップ（伝統的な縦書き配置：一番右が「あ行」、上段が右から「あ・か・さ…」）
* **1ファイル完結構造（オフライン・GitHub Pages対応）**
  * HTML / CSS / JavaScript の単一ファイル構成。外部通信なしで動作し、学習進捗はブラウザの `localStorage` に保持。

### (2) 出題＆ヒント表示のタイマー設計
1. **問題提示：** 最初に漢字（または対象語句）を表示。
2. **1.2秒後：** ひらがなの読みが浮かび上がる（フェードイン）。
3. **5.0秒後：** ローマ字ヒントを淡い文字で表示（待てば答えがわかる）。

### (3) ステージ・進行システム
* **10ステップの段階的難易度設定**
  * 各ステップ10語で構成し、ステップ内はランダム出題。
  * **Step 1:** 母音のみ（A, I, U, E, O）
  * **Step 2〜:** 子音1種類 → 子音2種類 → 揺れ・特殊音へ緩やかに難易度アップ。
* **クリア条件と進行状況バー**
  * 同じステップを **2回クリア（2周）** すると次のステップが自動アンロック。
  * 出題ブロック下部に「1〜10」の数字ボタンを配置。挑戦中（拡大・青）、クリア済み（緑＋クリアマーク `●●`）、未開放（鍵 `🔒`）を可視化し、タップで自由におさらいが可能。

### (4) 50音マップの定着度カラーロジック
* **未開放（グレー）：** 未入力の文字
* **ヒントあり入力（薄い黄色）：** ローマ字ヒント（5秒経過後）を見て入力（一定時間で色が薄れ、復習を促す）
* **自力入力（緑色）：** ヒント表示前に自力で入力成功
* **マスター（金色）：** ヒントなしで連続成功（デフォルトは2回）

### (5) 表記揺れ（訓令式 / ヘボン式 等）の動的切り替えヒント
* **複数入力パターンの許容**
  * `SI / SHI`（し）、`TI / CHI`（ち）、`TU / TSU`（つ）、`HU / FU`（ふ）、`TITI / CHICHI`（父）など、主要な日本語入力システムで通用する打鍵パターンをすべて正解判定。
* **動的ヒント書き換え（UX最適化）**
  * 初期状態は最もシンプルな標準ヒント（訓令式等）を1つだけ薄く提示（画面の混乱防止）。
  * 児童がヘボン式などの1文字目（例: `父` で `C`）を入力した瞬間、2文字目以降の薄文字ヒントがリアルタイムで `CHICHI` に自動変化する。
