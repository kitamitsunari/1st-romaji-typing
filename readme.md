# (My) 1st Romaji Typing / クイズグランプリ  -- w/Gemini 3.6 

**「打鍵習得」のためのツールとして、さらに「言葉の探究・知的好奇心」へつなげる小学生向けタイピング学習アプリ**

iPad（第10世代・横置き）のブラウザでスクロールなし・1画面完結で動作する、1ファイル構成（HTML/CSS/JS）のオフライン対応Webアプリです。

---

## 1. 開発のねらい・指導コンセプト

* **スモールステップでのつまずき解消**
  * 母音・子音・キー配置などの難易度を徐々に上げ、段階的に課題を提供。
* **知識学習とタイピング実践の並行（即時フィードバック）**
  * 50音表の暗記を前提とせず、知ったその場で打つ体験を繰り返し、記憶への定着を図る。
* **ヒント待ち時間の視覚化と心理的安全性**
  * 一定時間待つことで「読み（かな）」や「ローマ字（英字）」が浮かび上がる仕組みにより、「分からない」による挫折を防ぐ。
* **記憶の定着度を「50音マップ（図鑑）」の色彩で可視化**
  * 自力入力かヒント参照かにより50音マスの色（グレー・黄・緑・金色）が変化し、コンプリート欲を引き出す。
* **タイピングの先にある「豊かな言葉の世界」への誘導**
  * 「体と健康」「社会とお金」「自然と生き物」など、学問や科学への探究心を刺激する語句を出題。

---

## 2. 画面レイアウト・動作環境

* **iPad（第10世代・横置き 4:3）1画面完結型**
  * スクロール不要で全要素が収まるレイアウト設計。
    * **上段・左：** 出題カード ＆ ステップ/パネル選択バー
    * **上段・右：** 50音習得マップ（基礎） / 🏆クイズグランプリ選択盤（応用）
    * **下段：** 拡張4段 QWERTYソフトキーボード（打鍵フィードバックあり）＋ 「正解タッチ数」を掲示
* **1ファイル完結構造（GitHub Pages / オフライン対応）**
  * 外部通信や外部素材（画像・音声ファイル）非依存。学習進捗やハイスコアはブラウザの `localStorage` に保持。

---

## 3. 3つのステージ構成と狙い

### 🎵 1. 母音ウォームアップ モード
* ビート音（40〜180BPM可変）に合わせ、母音のみを打鍵。演劇の発声練習にちなむ。
* 音声合成による発声で、あ（A=エー）、え（E=イー）などの混線をほぐす。

### 🚀 2. ローマ字練習：基礎 モード
* **構成:** 1ステップ5語 × 10ステップ（全50語）。
* **スパイラル設計:** 新規登場音（6割）＋ 直前ステップの復習音（4割）。
* **解放システム:** 1周クリアで次のステップがアンロック。50音習得マップの完成をめざす。

### 🏆 3. クイズグランプリ：応用 モード
* **構成:** 3ジャンル（体と健康／社会とお金／自然と生き物）× 3難易度（10pt / 30pt / 50pt）＝ 全9パネル（各5問・全45問）。
* **スコア・記録:** 正解タッチ数のハイスコアを記録。スコア更新をモチベーションに再度の挑戦を促し、定着をはかる。

---

## 4. UI/UX ＆ システム要件

### (1) タイマー・ヒント設計
1. **問題提示:** 漢字（対象語句）を表示。
2. **1.2秒後:** ひらがなの読みがフェードイン。
3. **5.0秒後:** ローマ字ヒント（訓令式ベースの薄い文字）を表示。

### (2) 表記揺れ（訓令式 / ヘボン式等）の動的判定
* `SI/SHI`（し）、`TI/CHI`（ち）、`TU/TSU`（つ）、`HU/FU`（ふ）、`JIN/ZIN`（じん）など、主要な日本語入力パターンの表記揺れを全許容。
* 1文字目の入力（例: 「ち」で `C` を押下）に応じて、2文字目以降のヒント表示がリアルタイムで `CHICHI` に動的変化。

### (3) Web Audio API による合成音 SE ＆ 視覚演出
* 外部音声ファイルを使わずブラウザ上で音響をリアルタイム生成。
  * 正解音（チャリン高音）、ミス音（ブー低音）、語句クリア（ピロリン♪）、パネルクリア（ファンファーレ）。
* キー打鍵位置から当該のひらがなに向かって金色コインが飛翔するパーティクル演出。
